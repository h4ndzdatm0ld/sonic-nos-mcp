## About

The SONiC NOS MCP Server provides AI-powered tools for analyzing SONiC network device diagnostic data through the Model Context Protocol (MCP). It enables intelligent root cause analysis, streamlined troubleshooting workflows, and automated diagnostic procedures for SONiC environments.

For more information, see the [blog post](blog-sonic-nos-mcp-server.md) or the [main README](../README.md).
